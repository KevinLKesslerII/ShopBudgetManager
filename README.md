# ShopBudgetManager
A basic budget manager for a small shop.
Functionality includes adding sales and expenses, fixed expenses, clearing data, and viewing itemized lists of input sales and expenses.
Expenses have a check mark box that youcan check if that expense has been paid
Sales and expenses can be filtered by month/year
Program shows your monthly sales and total YTD, total overall, and net total after deducting input expenses to better help you track how much you have to play with
